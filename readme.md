Introduction GNSS, as a key infrastructure in modern society, provides core support for economic growth in multiple industries - mainstream constellations such as GPS, GLONASS, Galileo, BeiDou, not only ensure precise navigation and safe and efficient operation for vehicles, aircraft, ships but also play irreplaceable roles in precision agriculture planting (field surveying, agricultural machinery automation operations), telecommunication network synchronization, financial transaction timekeeping, etc. With technological advancement, the application scenarios of GNSS are expanding into emerging fields such as autonomous driving and the Internet of Things (IoT), where real-time positioning capability becomes a core requirement for intelligent technology upgrades.  
However, GNSS systems face severe malicious attacks: interference attacks cause legitimate GNSS signals to fail by transmitting interference signals, potentially endangering safety in critical areas such as traffic and emergency services; deception attacks are even more complex, by fabricating signals to induce receivers to generate incorrect location information, and the lack of built-in security features in GNSS further exacerbates its vulnerability.
4. Methodology Overview
This study's methodology revolves around three core steps: dataset construction, data preprocessing, and algorithm selection and optimization. The specifics are as follows:
- Datasets: Two specialized datasets for GPS deception detection and one for GNSS interference detection were utilized.
  - GPS Deception Detection Dataset: Containing 510,530 non-empty samples, covering 13 key features (pseudorandom noise, Doppler shift, pseudorange, carrier-to-noise ratio, etc.), including legitimate signals and three categories of deceptive signals: simple, intermediate, and complex.
  - GNSS Interference Detection Dataset: Based on the frequency spectrum image dataset converted from raw homodyne (IQ) data, containing six types of signals (AM interference, Linear Frequency Modulation (LFM) interference, Narrowband interference, No interference, Frequency Modulation (FM) interference, and ranging device signals), totaling 120,000 images.
Data preprocessing: To address the issue of class imbalance in the pseudo-detection dataset, random oversampling, random undersampling, and synthetic minority oversampling technique (SMOTE) were employed for balancing. Ultimately, a dataset with random undersampling was selected for model training (70% training set, 30% test set). For the interference detection dataset, the splitting ratio was optimized to 90% training set, 15% validation set, and 15% test set. Data augmentation techniques such as image scaling and normalization were used to enhance the model's robustness.
Algorithm selection:
• Pseudo-detection: Logistic regression, K-nearest neighbors (KNN), Gaussian Naive Bayes, Support Vector Machine (SVM), Decision Tree, Random Forest, XGBoost gradient boosting machine, and other machine learning algorithms were used. The hyperparameters were optimized through hierarchical shuffling and grid search cross-validation.
• Interference detection: ResNet18 was first used to extract image features, followed by training with traditional machine learning models such as random forest and decision trees. Custom convolutional neural networks (CNN) and ResNet18 (with both transfer learning and non-transfer learning training methods) were designed to improve detection performance.
Conclusion: The reliance on GNSS (especially GPS) in various industries continues to increase, and its vulnerability to pseudo-detection and interference threats has become an important risk affecting the safety of critical infrastructure.
